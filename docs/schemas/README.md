This folder contains JSON Schemas referenced by the documentation. They are provided to help validate and understand the shapes produced or consumed by the flows.

Included
--------

- manifest.schema.json — Section-aware per-spec manifest.
- spec-input.schema.json — Inputs accepted by create-spec (manual mode).

Notes
-----

- These schemas are documentation aids and may be more permissive than the flows.
- Line numbers in `lines` fields are 1-based, inclusive.
