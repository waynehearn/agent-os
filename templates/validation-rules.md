# Validation Rules

## Section Requirements

### Required Sections (Order)

1. Overview
2. User Stories
3. Spec Scope
4. Out of Scope
5. Expected Deliverable

### Count Constraints

- User Stories: 1-3
- Spec Scope items: 1-5
- Expected Deliverables: 1-3

### Content Requirements

- Overview: 1-2 sentences
- User Stories: Title + story + details format
- Deliverables: Externally verifiable outcomes

## Validation Actions

- VERIFY section order matches requirement
- VERIFY counts within constraints
- VERIFY format compliance
- REWRITE if validation fails
