# Tech Stack and Commands

## Tech Stack
- **Frontend**: HTML5 + CSS3 + Vanilla JavaScript (ES2020+)
- **Build**: None required - open `site/index.html` directly in browser
- **Testing**: Optional (light DOM/unit tests if desired)
- **Runtime**: Node.js v24.2.0 available, Git 2.49.0.windows.1
- **Platform**: Windows (Git Bash/WSL compatible)

## Development Commands
Since this is a static HTML/JS demo with no build process:

### View Demo
```bash
# Open in browser (Windows)
start site/index.html
# or manually open file in browser
```

### File Operations
```bash
# List files
ls -la
# View git status  
git status
# Edit files with any text editor
```

### No Special Commands Needed
- No package.json, no npm scripts
- No build process or bundlers
- No test framework configured (though unit tests could be added if needed)
- No linting/formatting tools configured

## Utility Commands (Windows/Git Bash)
- `ls` - list files
- `cd` - change directory  
- `git` - version control
- `grep` - search text
- `find` - find files
